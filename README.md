# ModelOps e Machine Learning

Materiali didattici per il corso **"ModelOps e Machine Learning"** - ITS ICT Piemonte, Gen AI Specialist B.F. 2025/2027.

## 📚 About This Repository

This repository contains the hands-on lab exercises for the course. Labs guide students through practical ModelOps and Machine Learning Operations workflows, including model lifecycle, deployment, registry, monitoring, explainability, governance, optimization, RL/RLHF, framework selection, and project work.

Each lab includes:

- goal + scenario
- step-by-step instructions
- expected output + verification checklist
- cleanup requirements and fallback options

## Verifica finale e distribuzione dei materiali

La verifica finale prevede **quiz individuale tratto esclusivamente dai mini-esercizi delle slide e presentazione del project work di gruppo**, senza esame orale separato. I due set da 30 domande si trovano in verifiche/: PDF per la prova, Markdown con soluzioni e XML Moodle per il docente.

Il calendario mantiene 60 ore: incontri 1–12 da 4 ore, progetto da 8 ore in due incontri, verifica finale da 4 ore. Non è previsto un deck separato per la verifica finale.

Per ogni lezione il docente condivide il PDF e, al momento del laboratorio, il relativo file Markdown e i CSV indicati nel lab. Per i laboratori di esercitazione le soluzioni vengono condivise dopo il tentativo degli studenti. Il Lab 13 guida il project work finale: gli studenti realizzano e consegnano la propria implementazione.

Per Lab 10: CSV testuale per il percorso Hugging Face e CSV cifre per confronto/fallback. Per Lab 13: scegliere un soggetto dal [catalogo dei progetti finali](labs/progetti_finali/README.md) e condividere il lab più la cartella assegnata (README, dataset.csv e richieste_monitoraggio.csv). Tutti gli otto soggetti sintetici hanno la propria coppia CSV in progetti_finali/.
