# ModelOps e Machine Learning

Materiali didattici per il corso **"ModelOps e Machine Learning"** - ITS ICT Piemonte, Gen AI Specialist B.F. 2025/2027.

## 📚 About This Repository

This repository contains the hands-on lab exercises for the course. Labs guide students through practical ModelOps and Machine Learning Operations workflows, including model lifecycle, deployment, registry, monitoring, explainability, governance, optimization, RL/RLHF, framework selection, and project work.

Each lab includes:

- goal + scenario
- step-by-step instructions
- expected output + verification checklist
- cleanup requirements and fallback options
